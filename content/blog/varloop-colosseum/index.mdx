The model is `thinkingmachines/TML-d24-varloop-research`, where N is the number of passes through its looped middle layers. I ran N = 1 to 5 and, for comparison, the official `thinkingmachines/Inkling-2-Mini`, which makes 3 fixed passes. On 24 November 2026 I served them with vLLM in tensor parallel on two RTX 5070 Ti, one server and one [pi](https://github.com/earendil-works/pi) coding agent at a time. pi edits files and runs commands on its own until it decides it is done.

Each server gave its agent the longest context its key-value (KV) cache could hold. The context shrinks as N grows: 736,128 tokens at N = 1, 162,688 at N = 5. For Inkling 2 Mini it was 301,056 tokens.

Each agent ran in its own container, started and watched by a script. To test its work it could run `pagecheck`, which opens the page in headless Chromium with software WebGL, at noon and at midnight. It reports JavaScript errors, pictures that are blank, too dark or overexposed, whether the scene moves, whether lights come on at night, and whether dragging and the mouse wheel work.

pi stops when the model answers without calling a tool. If an agent stopped before a passing `pagecheck`, the harness reopened the same session with a fixed message asking it to continue, up to 6 times. Each agent had 90 minutes in the first step and 45 in the second, restarts included.

## Results

All 12 pages, 6 from each step, pass the final `pagecheck` that the harness ran after each agent. Each time below runs from the agent's start to the end of that final check. In the first step each agent took from 11 min 39 s (N = 1) to 33 min 49 s (Inkling 2 Mini) and ran `pagecheck` 1 to 27 times. In the second step each agent took from 2 min 36 s (N = 4) to 7 min 20 s (N = 5).

At N = 2 to 5 the preview ends at night instead of back at noon. These pages limit how far a single frame can move the clock, so with the slow frames of software rendering their day lasts longer than 60 seconds.

The prompt asks for the whole tile in view at the default zoom. At N = 2 and N = 4 the camera starts too close, and at N = 3 the top and bottom corners of the tile are cut.

In the second step the agent of N = 5 ran `pagecheck` 7 times, always with a pass, but then deleted the folder where `pagecheck` keeps its log. The harness reads that log to decide whether to restart an agent, so it restarted this one 6 times, the limit.
