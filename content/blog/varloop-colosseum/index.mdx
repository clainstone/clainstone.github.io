The model is `thinkingmachines/TML-d24-varloop-research`, where N is the number of passes through its looped middle layers. I ran N = 1 to 5 and, for comparison, the official `thinkingmachines/Inkling-2-Mini`, which makes 3 fixed passes. On 24 November 2026 I served them with vLLM in tensor parallel on two RTX 5070 Ti, one server and one pi coding agent at a time.

The context window of each server was sized to fit its key-value (KV) cache. It was 736,128 tokens at N = 1 and fell with each added pass to 162,688 at N = 5. For Inkling 2 Mini it was 301,056 tokens.

Each agent ran in its own container, started and checked by a harness script. The `pagecheck` command opens the page in headless Chromium with software WebGL, at noon and at midnight. It reports JavaScript errors, blank, too dark or overexposed pictures, motion, night lights, dragging and the mouse wheel. When pi exited and the last `pagecheck` run in the log was not a pass, or there was none, the harness resumed the session with a fixed message. It did so at most 6 times per agent, within 90 minutes in the first step and 45 in the second, resumes included.

## Results

All 12 pages, 6 from each step, pass the final `pagecheck` that the harness ran after each agent. Times run from an agent's start to the end of that check. In the first step each agent took from 11 min 39 s (N = 1) to 33 min 49 s (Inkling 2 Mini) and ran `pagecheck` 1 to 27 times. In the second step each agent took from 2 min 36 s (N = 4) to 7 min 20 s (N = 5).

At N = 2 to 5 the minute of the preview ends at night. These pages cap the time step of each frame at 0.05 s, so their clock falls behind when frames are slow, as in software rendering.

The prompt asks for the whole tile in view at the default zoom. At N = 2 and N = 4 the camera starts too close, and at N = 3 the top and bottom corners of the tile are cut.

In the second step the agent of N = 5 ran `pagecheck` 7 times, always with a pass, but deleted its log. The harness reads that log to decide whether to resume an agent, and it resumed this one 6 times, the limit.
