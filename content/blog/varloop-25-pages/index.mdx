<Prompt />

The model is `thinkingmachines/TML-d24-varloop-research`, where N is the number of passes through its looped middle layers; I served it with vLLM in tensor parallel on two RTX 5070 Ti. On 23 November 2026 I ran only N = 1 to 5, with 5 pi coding agents per N working on this prompt one after another: 25 pages.

## Pages by N

I opened each page in a 1600 by 900 headless Chrome window and compared screenshots taken over several seconds. A page that moves by itself with no error works; a page that throws a JavaScript error, stays black or does not move is broken.

| N | Pages that work | Broken pages |
|---|---|---|
| 1 | 3 of 5 | 2 of 5 |
| 2 | 5 of 5 | 0 of 5 |
| 3 | 5 of 5 | 0 of 5 |
| 4 | 4 of 5 | 1 of 5 |
| 5 | 5 of 5 | 0 of 5 |

## The 25 pages

Each row gives the tokens the agent generated and, among them, the reasoning tokens. Max context used is the largest context the agent actually reached: the most tokens, input and output together, in any one of its requests. The speed, in tokens per second (tok/s), comes from pi's session log: tokens generated divided by the time pi recorded for the model's replies. Each link opens the page exactly as its agent wrote it; the link text is the page's title, cut before any subtitle.
